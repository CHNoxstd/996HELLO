## 一、项目概述
本项目为**公益性、规范性、学术性开源科普项目**。

项目依据《中华人民共和国劳动法》《中华人民共和国劳动合同法》及国际劳工组织核心公约内容，系统性整理、归纳、科普合法劳动用工标准与劳动者法定权益。

本项目**不针对任何企业、组织及个人进行评判、公示、定性或指控**。
所有内容仅基于公开生效的法律法规文本、公开司法判例，用于标准化学习、研究、科普与规范参照。

## 二、项目目标
1. 标准化普及合法劳动工时、休息休假、劳动报酬、加班核算制度。
2. 明确界定违规用工、超时用工的法定判定标准。
3. 结合真实司法案例，直观展示违规用工的后果与维权逻辑。
4. 提供合法、合规、正规的劳动权益维权途径与流程说明。
5. 倡导所有用工主体严格遵守属地劳动法律法规。
6. 推动规范化、法治化、可持续的劳动就业生态。

## 四、典型劳动违规案例（公开判例·脱敏版）
> 所有案例均取自**中国裁判文书网公开民事判决书**，已完全脱敏，无具体企业名称、无侵权风险，仅用于普法教育。

### 案例一：常态化无薪超时加班
**案情简述**

某用工单位长期要求员工每日工作10小时以上、单月休息不足2天，日常工作日超时工作、周末全员在岗，无加班工资、无调休、无劳动补偿。
企业内部制度默认“超时工作为常态”，将无偿加班纳入隐性工作要求。

**法院判决核心**
1. 用人单位工时制度严重超出国家法定标准工时。
2. 超出法定时长的工作时间，必须依法支付1.5倍、2倍、3倍加班薪资。
3. 企业隐性强制加班行为，属于违法侵害劳动者休息权与获酬权。
4. 最终判决企业足额补发全部加班薪资、承担诉讼相关费用。

### 案例二：强制自愿加班、变相剥夺休息权
**案情简述**

某单位不书面安排加班，但通过绩效、评优、工作压力等方式，变相强制员工夜间、周末持续工作，并要求员工签署“自愿加班承诺书”，试图免除企业法定责任。

**法院判决核心**
1. 劳动者签署的放弃休息权、自愿无偿加班协议无效。
2. 用人单位不得以任何形式规避劳动法定义务。
3. 变相强制加班属于明确违法行为，不受法律认可与保护。

## 五、项目核心观点（严谨客观·非情绪化）
1. **合法劳动时间是底线，不是福利**
每日8小时、每周法定工时、法定节假日，是法律赋予所有劳动者的刚性权利，并非企业给予员工的优待。

2. **效率不等于时长，透支劳动不等于敬业**
长期超时工作只会降低劳动效率、透支身心健康、制造无效内耗，无法长期维持企业良性发展。
合规、劳逸结合的用工模式，才是可持续的用工模式。

3. **任何口头、书面、变相的强制无偿加班，均不合法**
无论企业以制度、绩效、承诺书、企业文化为借口，都不能凌驾于国家劳动法律之上。

4. **劳动者维权不是对立，是合规自救**
主动了解、维护自身合法权益，是每一位劳动者的正当权利，不属于纠纷对抗，属于法治社会正常合规行为。

## 六、996违规行为明确拒绝准则（项目立场）
本项目**明确拒绝、不认可、不支持**以下所有违规用工行为：
1. 拒绝常态化996超时工作制，拒绝无视法定工时上限。
2. 拒绝无偿加班、强制加班、变相诱导加班。
3. 拒绝以绩效、辞退、评优、团队压力等方式胁迫劳动者放弃休息权利。
4. 拒绝将“超长工时”包装为企业文化、敬业标准。
5. 拒绝企业利用格式条款、自愿承诺书规避法定劳动责任。
6. 拒绝任何损害劳动者身心健康、违反法律法规的不合理用工制度。

> 本项目立场：
> **尊重劳动、尊重法律、尊重人权，坚持一切用工行为以国家法律法规为唯一标准。**
